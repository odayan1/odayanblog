プライバシーポリシー

運営者：小田木 正邦（事務所オダヤン）／制定日：2026年11月2日

このページは、odayanblog.com（以下「本サイト」）と、本サイトで公開している学習アプリ（Q-UP塾の練習アプリなど）、および運営者が管理するYouTubeチャンネル・Xアカウントでの情報の取り扱いについて定めたものです。

1. 集める情報

  • 学習アプリの記録：前回の点数・ベスト記録・途中までの記録などは、お使いの端末のブラウザの中（localStorage）にだけ保存されます。運営者のサーバーには送られず、運営者が見ることはできません。ブラウザのデータを消すと記録も消えます。
  • アクセスの集計：ページやボタンが何回使われたかを知るため、Cookieを使わないアクセス解析（GoatCounter）を使うことがあります。個人を特定できる情報は集めません。
  • お問い合わせ：メールでお問い合わせいただいた場合、お名前・メールアドレス・お問い合わせ内容を、ご返信と対応のためにだけ使います。

2. Google API（YouTube Data API）の利用について

運営者は、自分が管理するYouTubeチャンネルの運営（動画のアップロード、説明文・再生リストの編集、コメントへの返信の投稿など）のために、Googleの YouTube Data API を利用しています。

  • 認証して利用するのは、運営者本人のGoogleアカウントとチャンネルだけです。第三者のアカウントにログインを求めたり、第三者のGoogleアカウントのデータを取得したりすることはありません。
  • 視聴者のみなさんのコメントは、返信のために読み取ることがありますが、それ以外の目的には使わず、第三者に提供・販売しません。
  • Google API から受け取った情報の利用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
  • YouTube の利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。

3. 第三者への提供

法令にもとづく場合を除き、集めた情報を本人の同意なく第三者に提供することはありません。

4. 外部サービスへのリンク

本サイトには YouTube・X などへのリンクがあります。リンク先での情報の取り扱いは、それぞれのサービスの方針に従います。

5. 改定

このポリシーは、必要に応じて改定することがあります。改定した場合は、このページでお知らせします。

6. お問い合わせ

このポリシーについてのお問い合わせ：home-tutor@odayanblog.com
